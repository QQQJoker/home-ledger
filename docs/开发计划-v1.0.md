---

## 1. 计划目标与约束

### 1.1 目标

在 4 周内交付可自用的 v1.0 APK，满足需求文档第 8 章全部验收项：

- 可记收入/支出、可编辑删除、可筛选；
- 分类与账户管理可用；
- 首页与统计口径一致，三类图表可用；
- 仅本地存储，支持加密备份恢复；
- 应用锁生效；
- 明确不包含预算/云同步/成员功能。

### 1.2 已确认技术决策（锁定）

- 图表库：Vico
- 备份加密：AES-GCM（启用）
- 月度对比默认：最近 6 个月
- 分类排序：v1 固定顺序 + 置顶
- 架构：单模块分包（按 feature + 分层边界）

### 1.3 交付约束

- 全离线，不依赖网络；
- 金额统一 `Long(分)` 存储，不使用浮点；
- 统计统一按 `occurredAt` 归属；
- 关键写操作使用事务，异常不吞。

## 3. WBS 任务拆解（可直接执行）

## 3.1 第 1 周（M1：数据层与记一笔闭环）

### D1：项目初始化与基础框架

- 创建 Android 工程（Kotlin + Compose + Material3 + Hilt + Room）
- 建立 package 结构：
  - `core/common`、`core/database`、`core/model`、`core/backup`
  - `feature/home`、`feature/entry`、`feature/ledger`、`feature/stats`、`feature/settings`
- 建立基础导航框架（4 Tab 空页面 + 记一笔入口占位）
- 配置基础 CI 命令（至少本地 `test` + `assembleDebug`）

**验收**
- 工程可编译可运行；
- 基础导航可切换；
- Hilt 注入链路可用。

### D2：数据库实体与 DAO

- 建立 `TransactionEntity`、`CategoryEntity`、`AccountEntity`
- 定义外键、唯一约束、索引
- 建立 DAO：
  - 交易增删改查、分页、筛选
  - 分类/账户 CRUD 与关联计数查询
  - 统计聚合查询（先提供接口，后续接图表）

**验收（对应 F-01~F-05、F-07、F-13~F-15）**
- 实体与约束落地；
- 核心查询可跑通；
- 金额使用分存储。

### D3：初始化数据与 Repository

- 首次启动初始化预设分类与预设账户（幂等）
- 实现 Repository（Transaction/Category/Account）
- 统一金额转换工具（`cent <-> decimal string`）
- 时间范围工具（今日/本周/本月/本年/自定义）

**验收**
- 重启不重复插入预设数据；
- Repository 提供 ViewModel 所需接口。

### D4~D5：记一笔（最小闭环）

- 记一笔页面：
  - 类型切换、金额输入、分类选择、账户选择、时间选择、备注
- 表单校验：
  - 必填校验、金额合法性、备注长度限制
- 保存后返回并刷新数据源（Flow）

**验收（对应 F-01~F-06）**
- 3 步内完成保存；
- 保存后可在数据库查到正确记录；
- 错误输入有明确提示。

---

## 3.2 第 2 周（M2：核心体验）

### D6：流水列表与分组展示

- 按 `occurredAt DESC` 展示
- 同日分组（今天/昨天/日期）
- 列表项显示类型、分类、账户、金额、时间、备注摘要

**验收（F-07、F-08）**
- 列表排序与分组正确；
- 收支视觉区分清晰。

### D7：流水详情、编辑、删除

- 详情页展示全字段
- 编辑页复用记一笔组件
- 删除二次确认弹窗

**验收（F-09、F-11、F-12）**
- 编辑后统计联动更新；
- 删除操作可追踪、可感知。

### D8：筛选功能

- 时间范围筛选：今日/本周/本月/本年/自定义
- 类型筛选：全部/收入/支出
- 分类、账户筛选

**验收（F-13、F-14、F-15）**
- 组合筛选结果正确；
- 筛选与列表分页兼容。

### D9：分类管理

- 预设分类：隐藏/显示，不可删除
- 自定义分类：新增、编辑、删除（有关联流水阻断）
- 同类型名称唯一校验
- 排序：固定顺序 + 置顶

**验收（F-20~F-24）**
- 规则满足业务约束 BR-03、BR-06。

### D10：账户管理 + 首页基础数据

- 账户新增、编辑、停用（有关联不可删除）
- 记一笔默认上次使用账户
- 首页显示本月收入、支出、结余与最近流水

**验收（F-30~F-33、F-50~F-52）**
- 首页口径与统计查询源一致；
- 满足 BR-04、BR-05。

## 3.3 第 3 周（M3：统计、安全、备份）

### D11：统计聚合查询与汇总卡

- 周期切换联动（今日/本周/本月/本年/自定义）
- 汇总卡（收入/支出/结余）
- 支出分类排行列表与跳转筛选

**验收（F-40~F-42、F-47、F-48）**
- 全部按 `occurredAt` 归属；
- 首页与统计页一致。

### D12：图表（Vico）

- 支出分类占比图（TopN + 其他）
- 收支趋势折线图（短周期按日，长周期按周/月）
- 月度对比柱图（默认 6 个月）
- 空数据状态与“记第一笔”入口

**验收（F-43~F-46）**
- 图表数据与汇总值一致；
- 空态体验完整。

### D13：备份导出（AES-GCM）

- 导出结构定义（含 schemaVersion、导出时间）
- 数据序列化（分类、账户、流水）
- 用户输入密码后执行加密写文件（SAF）

**验收（F-61）**
- 可生成加密备份文件；
- 密码错误不允许伪成功导出。

### D14：恢复导入（全量覆盖）

- 读取文件 -> 解密 -> 版本校验 -> 覆盖恢复（事务）
- 恢复前二次确认
- 失败回滚与错误提示

**验收（F-62）**
- 导出 -> 恢复形成闭环；
- 异常时数据不被破坏。

### D15：应用锁

- 启动解锁/后台超时解锁（默认 5 分钟）
- 支持 PIN 或生物识别（至少一种必须稳定）
- 锁状态与页面生命周期联动

**验收（F-63）**
- 后台超时后返回前台必须验证；
- 可配置超时阈值（默认值可用）。

## 5. Definition of Done（完成定义）

每个功能任务“完成”必须同时满足：

1. 代码已合入主干（或当前开发分支）；
2. 单元测试/关键集成测试通过；
3. 关联需求编号有验收证据（截图或录屏）；
4. 关键异常路径可感知（有提示，不吞异常）；
5. 不引入范围外功能（预算/云同步/成员）。

## 7. 风险、依赖与缓冲

### 7.1 高风险项

1. 图表显示与聚合数据不一致  
2. 恢复流程异常导致数据损坏  
3. 生命周期复杂导致应用锁误触发  
4. 筛选与分页耦合导致边界缺陷

### 7.2 应对策略

- 聚合结果先做统一数据层，再喂给图表；
- 恢复流程全事务 + 恢复前自动备份；
- 应用锁先实现最小稳定方案（PIN），生物识别可增强；
- 对筛选组合建立固定回归用例集。

### 7.3 缓冲使用规则（2 人日）

- 仅用于：阻塞级缺陷、数据一致性问题、备份恢复问题；
- 不用于新增需求。
